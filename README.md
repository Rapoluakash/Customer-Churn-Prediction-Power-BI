# Customer-Churn-Prediction-Power-BI


## Key Insights

1. Approximately 26.6% of customers churned while 73.4% remained active.

2. Customers with month-to-month contracts showed a higher tendency to churn.

3. Most customers were classified as Low Risk, while a smaller group was identified as High Risk.

4. The Random Forest model was used to predict customer churn and identify at-risk customers.

5. Power BI was used to build an interactive dashboard for churn analysis and business decision-making.
